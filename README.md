## 自己添加品牌

1. 进入店主工作台，在“品牌管理”填写品牌名称并选择颜色，点“保存新品牌”。
2. 新品牌会立刻出现在商品发布表单和当前设备的买家首页；自定义品牌使用品牌名称的前两个字符作为图标。
3. 在品牌列表中可随时修改颜色。删除品牌时，该品牌已有商品会自动归入 **Other Brands**，不会丢失。
4. 品牌设置只在当前设备保存；要让所有客户看到，请点“导出 products.js”，再到 GitHub 覆盖旧文件并提交。导出的 `products.js` 同时包含品牌设置和商品数据。

## 发布步骤

1. 解压 ZIP。
2. 登录 GitHub，新建一个 **Public** 仓库。
3. 选择 **Add file → Upload files**，把解压后的全部文件和 `assets` 文件夹上传到仓库根目录并提交。
4. 进入 **Settings → Pages**；选择 **Deploy from a branch**，Branch 选 `main`，目录选 `/ (root)`，保存。
5. GitHub 显示发布地址后，用中国大陆手机流量、Wi-Fi 和微信内置浏览器分别测试。

GitHub Pages 在中国大陆不同网络的访问速度可能波动，不能保证所有运营商始终可打开。

## 店主发布商品

1. 在主页点“店主入口”，输入固定密码 **9611**。
2. 按拍摄清单准备照片：整体、吊牌价签、细节或瑕疵。每件最多上传 3 张，第一张是主图。
3. 选择品牌，填写商品名、款号、颜色、尺码、人民币报价、门店原价、库存总数和报价包含项目。找不到品牌时，先在“品牌管理”添加；商品发布表单不再要求所在门店、截单时间或补充说明。
4. 点“保存并预览”。商品会按品牌自动归类，并生成商品信息查询编号；当前手机可立即预览。
5. 点“导出 products.js”，到 GitHub 仓库上传新文件，覆盖旧文件并提交。Pages 更新后，所有客户才能看到。

照片会在浏览器里压缩并嵌入 `products.js`。多张图片会让文件变大；若手机提示空间不足，请先导出，再删除部分本机商品或改用更小的图片。


## 付款与订单流程

客户点“复制商品去微信”，把带商品信息查询编号的信息粘贴给店主。商品页价格是店主发布前定好的一口价，不在微信重新报价。微信环节只确认商品信息查询编号、库存、颜色和尺码，再由店主发送收款二维码。网站不展示二维码、不在线收款。

### 库存与客户确认

1. 客户带商品信息查询编号来问时，在“库存与客户确认”中点“登记待确认”。这一步只记录有人在问，不扣库存。
2. 客户说不要了，点“取消待确认”；剩余库存不会变化。
3. 客户确定购买时，点“确认售出 −1”；系统才会扣 1 件。若点错，可点“撤销售出 +1”恢复。
4. 同一商品有多件时，页面会显示总数、待确认、已售和剩余数量；全部卖完后自动显示“已售罄”。
5. 库存变化先保存在店主当前设备；要让客户看到新库存，仍需导出并覆盖 GitHub 上的 `products.js`。

### 订单自动核对

1. 在店主工作台选择商品信息查询编号，系统自动带出品牌、款号/商品款、颜色、尺码和一口价。
2. 按客户订单填写对应信息与实收金额，再分别上传客户付款截图和店主收款截图。
3. 七项全部一致/齐全后，绿色“✓ 下单成功”会自动出现，不需要手动点击。
4. 商品会在当前设备自动增加 1 件“已售”并扣减 1 件剩余库存；导出并覆盖 GitHub 上的 `products.js` 后，客户商品卡才会显示最新剩余数量。

系统只核对两张截图是否上传，不读取截图里的金额；请店主亲自查看截图内容。截图经压缩后仅存在当前设备的浏览器本地记录，不会写入导出的 `products.js`。上传前请遮住姓名、账号等隐私，用完可在工作台清空核对记录。

### 客户档案（仅店主当前设备）

1. 订单自动核对时填写客户昵称；同一昵称会被识别为同一位客户。
2. 核对成功后，档案自动累计购买次数、累计金额、首次购买时间和最近购买时间；店主可另加备注标签。
3. 客户档案不设微信号字段，也不要在备注里写电话、地址、账号等隐私。
4. 档案只保存在店主当前设备的浏览器中，不会写入 `products.js`、不会出现在买家页面，也不要上传到 GitHub。
5. 固定店主密码只能防误触，不是安全后台；离开页面时请点“锁定”。清除浏览器数据或换设备会丢失本机档案。

### 发货归档

1. 订单出现绿色“✓ 下单成功”后，在该订单下方填写面单上的物流信息查询编号，并上传面单照片。
2. 物流信息查询编号和面单照片两项齐全后，系统自动显示绿色“✓ 已发货”，不需要再点确认按钮。
3. 面单照片只保存在店主当前设备，不会写入 `products.js`；请先遮住姓名、电话和收货地址。
4. 物流信息查询编号会自动写入该商品资料。再次导出并覆盖 GitHub 上的 `products.js` 后，客户商品卡显示“✓ 已发货”和物流信息查询编号。

注意：GitHub Pages 商品页是公开页面，发布后的物流信息查询编号任何访客都可能看到。若不希望公开，请不要导出物流信息查询编号，继续只在微信里发给客户。

服装国际段页面写的是 **$7/磅参考价**；最终按实际重量和承运渠道计算。代购商品下单采购后不退不换；若现场缺货或涨价且客户未确认，退回对应商品款。税费及其他费用应在付款前逐单确认。
